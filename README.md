# Jogo de Nave 3D (On-Rails)

Protótipo de jogo de nave 3D no navegador, estilo on-rails (Star Fox 64) com clima de Star Wars.
Feito com React + Vite + Three.js + React Three Fiber + Drei.

## Rodar localmente

```bash
npm install
npm run dev
```

## Controles

- Mouse ou WASD / setas: mover a nave
- Clique ou Espaço: atirar

## Ajustes

Toda a física da nave, da câmera, dos tiros e dos asteroides fica no `CONFIG` em `src/gameState.js`.
